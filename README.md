#  Orbverse - Plataforma Mobile de Venda de Jogos 🎮

O **Orbverse** é uma plataforma mobile de venda e gerenciamento de jogos, inspirada em grandes lojas de PC como **Steam** e **Epic Games**.

Desenvolvido em **React Native** com **Expo (Blank + TypeScript)**.

**Projeto acadêmico desenvolvido para a disciplina de Programação para Dispositivos Móveis**, contemplando exclusivamente o desenvolvimento do frontend da aplicação.

## 💡 Sobre o Projeto

**Este projeto foi desenvolvido com fins acadêmicos para a disciplina de Programação para Dispositivos Móveis.**

O objetivo do Orbverse é proporcionar uma **experiência mobile moderna**, com uma interface intuitiva para o usuário, permitindo:

- **Login e Cadastro**
- **Compra de jogos** (interface)
- **Visualização da Biblioteca**
- **Gerenciamento do Perfil**
- **Instalação remota** (interface)

**Escopo do projeto:** desenvolvimento exclusivamente frontend, sem implementação de backend próprio.

## 🚀 Tecnologias Utilizadas

O projeto foi desenvolvido utilizando as seguintes tecnologias:

- **React Native**
- **Expo** (Template Blank + TypeScript)
- **TypeScript**
- **React Navigation** (Para navegação entre telas)
- **Firebase Authentication** (Autenticação de usuários)

## ▶️ Como Executar o Projeto

Siga os passos abaixo para executar o Orbverse localmente:

1. **Clonar o repositório:**

   ```bash
   git clone https://github.com/leticiasilva09/orbverse.git
   ```

2. **Instalar as dependências:**

   ```bash
   npm install
   ```

3. **Executar o projeto:**

   ```bash
   npx expo start
   ```

   *Para executar a aplicação, utilize um Development Build compatível com o projeto.*
