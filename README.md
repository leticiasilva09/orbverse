# 📱 Orbverse

## Plataforma Mobile de Venda de Jogos 🎮

O **Orbverse** é uma plataforma mobile de venda e gerenciamento de jogos, inspirada em grandes lojas de PC como **Steam** e **Epic Games**.

Desenvolvido em **React Native** com **Expo (Blank + TypeScript)**.

---

## 💡 Sobre o Projeto

**Este projeto foi desenvolvido com fins acadêmicos.**

O objetivo do Orbverse é fornecer uma **experiência completa e moderna** para o usuário, permitindo:
* **Login e Cadastro**
* **Compra de jogos**
* **Visualização da Biblioteca**
* **Gerenciamento do Perfil**
* **Instalação remota**

---

## 🚀 Tecnologias Utilizadas

O projeto é construído com as seguintes tecnologias:

* **React Native**
* **Expo** (Template Blank + TypeScript)
* **TypeScript**
* **React Navigation** (Para navegação entre telas)

## ▶️ Como Executar o Projeto

Siga os passos abaixo para rodar o Orbverse localmente:

1.  **Clonar o repositório:**
    ```bash
    git clone [https://github.com/seu-repo/orbverse.git](https://github.com/seu-repo/orbverse.git)
    ```

2.  **Instalar dependências:**
    ```bash
    npm install
    npx expo install
    ```

3.  **Rodar o projeto:**
    ```bash
    npx expo start
    ```
    *Use o app Expo Go no seu celular para escanear o QR code.*
